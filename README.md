# LipatoS — Нагрузка

Foundry VTT v14 / D&D5e 6.0.6.

В модуле используются уже вычисленные системой D&D5e значения переносимого веса и пороги на встроенной полоске инвентаря. Своего параллельного счётчика предметов нет.

- Нагрузка — скорость −10 футов.
- Сильная нагрузка — скорость −20 футов и помеха на атаки, проверки и спасброски Силы, Ловкости, Телосложения.
- Перегрузка — скорость 0 и та же помеха.
- На любом уровне модуль снимает предыдущую ступень, чтобы штрафы не складывались.
- GM синхронизирует эффекты; игрок не может перемещать токен при скорости 0.
- В бою длина движения считается по встроенной в Foundry v14 стоимости пути и истории перемещений.
- Для игрока доступен метод API useDash(tokenDocument) — расходует действие «Рывок» один раз в ход и добавляет скорость к доступному перемещению; кнопка находится в модуле Buffs-Debuffs.
- Перемещение мастера не ограничивается.

**Примечание:** действие «Рывок» фиксируется этим модулем как потраченное. Учёт других использованных действий персонажа сторонними модулями не интегрирован.

Зависимости: Foundry 14, dnd5e 6.0.6. С модулем LipatoS — Buffs & Debuffs появляется панель и кнопка «Рывок».

## Иконки уровней нагрузки (v0.1.1)

- Жёлтая гиря — «Нагрузка» (−10 футов).
- Оранжевая гиря — «Сильная нагрузка» (−20 футов, помеха).
- Красная гиря — «Перегрузка» (скорость 0, помеха).

Все три изображения включены в установочный архив по путям `assets/icons/encumbrance-1.jpg` и далее. Модуль обновляет иконку существующего эффекта при следующей синхронизации, даже когда степень нагрузки не менялась.
